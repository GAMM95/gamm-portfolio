
# PORTAFOLIO - GAMM95

Este es mi portafolio personal desarrollado en React y estilizado con Tailwind CSS, diseñado para mostrar mis proyectos, habilidades y permitir que visitantes me contacten fácilmente. Está optimizado para dispositivos móviles y de escritorio.

## 📱 Características principales
- Interfaz moderna y responsiva, funciona en móviles, tablets y escritorio. 
- Secciones claras: acerca de mí, habilidades, proyectos, experiencia laboral, contacto.
- Formulario de contacto con envío por JS Mail.
- Mensajes de confirmación y error con Toastr.
- Navegación suave entre secciones.

## 🚀 Instalación y ejecución local
### 1. Clonar el repositorio: 
```
git clone https://github.com/GAMM95/gamm-portfolio.git
```

### 2. Entra a la carpeta del proyecto:
```
cd gamm-portfolio
```

### 3. Instalar las dependencias:
```
npm install
```

### 4. Ejecutar el proyecto:
```
npm start
```

## 📄 Estructura del proyecto
```
gamm-portfolio/
├─ public/
├─ src/
|  ├─ assets/         # Imágenes, archivos CSS, etc.
│  ├─ components/     # Componentes reutilizables
│  ├─ pages/          # Páginas del proyecto
│  ├─ App.jsx         # Componente raíz
|  ├─ index.css       # Estilos globales
│  ├─ index.js        # Entrada principal del proyecto
├─ tailwind.config.js # Configuración de Tailwind CSS
├─ package.json
└─ README.md
```

## 📬 Formulario de contacto
El formulario permite que usuarios me envíen un mensaje directamente desde el sitio.
- Se envía con JS Mail.
- Toastr muestra notificaciones de éxito o error.
- Validación básica para campos obligatorios.


## 🎨 Estilos y responsividad
El diseño está construido con Tailwind CSS, lo que permite:
- Layouts responsivos sin frameworks pesados.
- Estilos consistentes con utilidades de clase.
- Adaptación fluida a diferentes resoluciones.
